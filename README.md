# BMI Calculator

This is a simple web-based BMI (Body Mass Index) calculator built with React. Users can input either **imperial** (lbs/inches) or **metric** (kg/cm) data to calculate their BMI. The application also displays a helpful chart of BMI ranges for reference.

# Features

* Toggle between **Imperial** and **Metric** units

* Instant BMI calculation on input

* Clear display of BMI result and category

* BMI classification chart included
